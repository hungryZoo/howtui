# howtui

AI 기반 터미널 명령어 도우미. 자연어로 쉘 명령어를 생성하고, 기존 터미널 안의 Inline TUI에서 직접 편집하거나 AI에 후속 수정을 요청한 뒤, 최종 명령어를 쉘 입력란 또는 stdout으로 전달하는 프로그램.

> 개발 원칙: 기존 터미널을 대체하지 않고, 어떤 환경에서도 AI 명령어 생성과 편집을 안전하고 가볍게 제공한다.

## 현재 상태

- Phase 0 (요구사항 명세와 기술 검증) 진행 중
- 설치 가능한 릴리스 없음
- 생성 명령어 자동 실행 없음 (설계 원칙)
