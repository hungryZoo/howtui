# ADR-0003 stdout 계약과 종료 코드

- 상태: 제안
- 일자: 2026-10-22
- 관련: PRD-OUT 계열, PRD-CLI-010, SRS 8절

## 결정

- 확정 시 stdout 출력: 명령어 UTF-8 바이트 + LF 1개. 명령어 내부 줄바꿈은 LF 그대로 유지, CRLF 변환 없음.
- 취소, 오류 시 stdout 0바이트.
- 종료 코드:

| 코드 | 의미 |
| --- | --- |
| 0 | 확정 명령어 출력 완료, 또는 하위 명령 성공 |
| 1 | 내부 오류 (분류 불가 오류) |
| 2 | 사용법 오류 (clap 기본값) |
| 3 | 사용 가능한 터미널 없음 (제어 터미널 부재, 커서 위치 질의 무응답) |
| 4 | 인증 필요 또는 인증 실패 |
| 5 | 플랜 비대상 또는 사용량 한도 초과 |
| 6 | 네트워크 오류 또는 일시 장애 |
| 7 | Provider 오류 (모델 미지원, 응답 형식 오류, 권한 구성 오류) |
| 8 | 설정 오류 |
| 101 | panic (Rust 기본값 유지) |
| 129 | SIGHUP 수신 종료 |
| 130 | 사용자 취소 (Ctrl+C, Esc) |
| 143 | SIGTERM 수신 종료 |

- TUI 모드의 LLM 오류는 종료 사유가 아님 (화면 표시 후 계속). 코드 4-7은 비대화형 모드와 하위 명령에서 사용.
- doctor 종료 코드는 별도 규칙 (0: 실패 항목 없음, 1: 실패 항목 존재).

## 근거

- 130은 128 + SIGINT 관례. 쉘 어댑터가 취소와 오류를 구분하는 기준. SPIKE-03/04/05에서 130 판정으로 입력란 보존 동작 확인.
- 3은 TTY 없는 환경을 일반 오류와 구분하기 위한 값. 스크립트에서 `--no-tui` 전환 판단 근거.

## 대안

- (a) sysexits.h 값(64-78): 쉘 사용자 인지도 낮음, 범위 과다로 기각.
