# ADR-0012 규칙 기반 위험 명령어 경고

- 상태: 제안
- 일자: 2026-10-22
- 관련: PRD-SAFE-002-005, SRS 16절

## 결정

- 정적 규칙 표 기반 판정. 외부 프로세스 실행, 파일 시스템 조회, 네트워크 조회 없음.
- 쉘별 토큰화: 공백, 따옴표, 파이프와 연결 연산자(`|`, `&&`, `||`, `;`, 줄바꿈) 기준 단순 분리 후 명령 단위 검사.
- 위험 수준 2단계: 주의(경고 표시), 높음(경고 표시 + 확정 재확인).
- 모델이 제시한 주의 사항은 설명 영역 보조 정보로만 사용, 수준 판정에 미반영.
- 문서와 도움말에 "완전한 보안 방어 수단 아님" 명시.

## 근거

- 지시서 10절: 규칙 기반 최소 검사 우선, 완전한 방어 수단으로 설명 금지.
- 규칙 판정은 결정적이며 문자열 단위 테스트로 검증 가능 (실제 시스템 변경 없음).

## 대안

- (a) LLM 판정 기반 (Atuin AI 방식): 결정성 부족, 모델별 편차로 1차 기준 기각.
- (b) 실제 쉘 파서 사용 (예: tree-sitter-bash): 의존성 증가, PowerShell 별도 필요로 기각.
