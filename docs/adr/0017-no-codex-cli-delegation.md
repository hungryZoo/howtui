# ADR-0017: Codex CLI 바이너리 위임 미채택

- 상태: 승인 (사용자 위임 판단, 2026-10-23)
- 관련: [research/codex-cli-delegation.md](../research/codex-cli-delegation.md) 9-1절, CR-005, PRD-PRIV-002, MRD-EXC-006

## 배경

사용자 제안 "codex가 설치되어 있으면 바이너리를 바로 사용" (2026-10-22). 사용자가 실험 후 판단을 위임 (2026-10-23).

## 결정

`codex exec` 서브프로세스 Provider를 구현하지 않는다. 에이전트 선택은 TUI 설정 화면(CR-005)에서 제공하고, 대상은 howtui가 직접 구현한 Provider로 한정한다.

## 근거

| 항목 | 내용 |
| --- | --- |
| 개인정보 보장 | 공식 텍스트 전용 모드 없음. 0.164.0에서 알려진 플래그를 모두 적용해도 JavaScript 실행 도구와 하위 에이전트 도구가 요청에 포함됨. 실계정 카나리아 시험에서 모델이 파일 읽기를 위해 도구를 3회 호출했고 Codex 내부에서 모두 차단됨(파일 미노출). 시도는 JSONL에 표시되지 않음. 파일 내용 미수집 원칙(PRD-PRIV-002)이 Codex 내부 실패 동작에 의존 |
| 안정성 | 기능 플래그 목록이 버전마다 변경 (1주 사이 기본 활성 도구 4개 추가) |
| 비용 | 요청당 Codex 지시문 약 2만 자 추가. 실측 입력 토큰: 단순 생성 7,330, 도구 시도 포함 29,408 |
| 목적 대비 효과 | 로그인 간소화는 CR-002로 해결. Codex 저장 로그인도 갱신 실패 시 별도 로그인 필요 |
| 프로세스 실행 규칙 | 현재 src의 프로세스 실행 0곳 규칙(TC-SAFE-001) 유지 |

## 재검토 조건

Codex CLI가 도구 정의 없이 텍스트 응답만 반환하는 공식 모드를 문서화하는 경우.
